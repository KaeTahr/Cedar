FIgure \ref{fig:cedar-architecture} illustrates Cedar's compiler, as designed
by Anderson~\autocite{cedar_george}. This project leaves the design unchanged,
and builds upon the two-phase structure, extending the second phase with 
code generation capabilities as well as completing the first phase's
parsing, and lexing components.
