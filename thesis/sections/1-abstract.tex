\abstract{
    In systems programming, such as in device drivers and network stacks, programmers
    rely on precise control over how data structures are represented in memory.
    In the C programming language, these details are typically implicitly
    expressed through field order, alignment directives, or compiler-specific
    pragmas. Such mechanisms are powerful but error-prone, and layout
    inconsistencies remain a major source of system faults and
    security vulnerabilities.

    Cedar is a declarative programming language that addressess this problem
    by
    specifying memory layouts explicitly within the C programming ecosystem.
    Building on ideas from Dargent, a verified layout
    description language integrated into Cogent, Cedar explores how
    the same declarative principles can be applied directly to C development.
    It treats data layouts as first-class constructs, allowing
    programmers to describe structure and placement at the byte level
    while preserving compatibility with existing compilers.

    By making layout intent explicit and statically checkable, Cedar
    provides a practical foundation for trustworthy data-layout
    design without requiring new programming models or
    heavy verification infrastructure. The approach demonstrates
    many of the benefits of formal reasoning, such as clarity,
    compositionality, and predictability, can be achieved through
    careful language design alone. Cedar thus contributes a middle ground
    between low-level programming and fully verified systems: a lightweight,
    expressive framework that improves the transparency and reliability of C
    data representations.
}
